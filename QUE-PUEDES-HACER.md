# ¿Qué puede hacer GitHub Copilot?

_GitHub Copilot es un programador de IA que te ayuda a escribir código más rápido y con menos trabajo._

## Capacidades principales de GitHub Copilot:

### 1. **Sugerencias de código inteligentes**
- Ofrece sugerencias de autocompletado directamente en VS Code y Codespaces
- Sugiere líneas individuales y funciones completas instantáneamente
- Se basa en el contexto de comentarios y código existente

### 2. **Soporte multilenguaje**
- Funciona con muchos editores de código: VS Code, Visual Studio, JetBrains IDE, y Neovim
- Entrenado en todos los lenguajes que aparecen en repositorios públicos
- Especialmente efectivo con Python, JavaScript, TypeScript, Ruby, Go, C# y C++

### 3. **Generación de código desde comentarios**
```javascript
// Crear un servidor web
function createWebServer() {
    // Copilot puede sugerir automáticamente la implementación completa
}
```

### 4. **Múltiples opciones de sugerencias**
- Proporciona hasta 10 sugerencias diferentes para el mismo problema
- Permite elegir la mejor solución para tu contexto específico
- Accesible através del panel de completado de GitHub Copilot

### 5. **Integración perfecta con Codespaces**
- Configuración automática en contenedores de desarrollo
- Fácil acceso a todas las herramientas de [Coding Colaborativo](https://github.com/features#features-collaboration) de GitHub
- Funcionamiento inmediato sin configuración adicional

## ¿Cómo empezar?

1. **Configura tu Codespace** con la extensión de GitHub Copilot
2. **Escribe comentarios** describiendo lo que quieres hacer
3. **Deja que Copilot sugiera** el código por ti
4. **Acepta, modifica o explora** diferentes opciones

### Tecnología

GitHub Copilot está impulsado por OpenAI Codex, un modelo de lenguaje generativo preentrenado creado por OpenAI, que proporciona sugerencias contextuales y precisas para acelerar tu flujo de trabajo de desarrollo.
